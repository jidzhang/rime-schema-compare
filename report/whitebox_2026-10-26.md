# Rime 方案白盒横评（2026-10-26）

## 口径

- 引擎：librime 进程内白盒（`lib/rime.dll`），无 GUI、无按键模拟、不开 WeaselServer；
- 输入：连续全拼（无分隔、无声调），句末空格取**首选**；与主仓黑盒口径一致（含归一化：他/她/它→他、的/地/得→的）；
- 零用户词库：每轮启动前清 `*.userdb`，并以 `{schema}.custom.yaml` 补丁禁用 `translator/enable_user_dict`；
- 隔离：每方案独立 `vendor/<dir>` 作 user_data_dir，与 `%APPDATA%\Rime`（小狼毫桌面配置）完全无关；
- 语料：主仓 `corpus/zhihu120.txt`（整句，n=120，≥5 字）、`corpus/words234.txt`（词级，n=450，≥2 字，`RIME_BENCH_MIN_HANZI=2`）；
- 明月简体 `luna_pinyin_simp` 为基准；魔然（自然码双拼+形码）因输入维度不同，经确认不参与。

## 可重复验证（三道闸记录）

1. **确定性**：zhihu120 两轮独立运行 600 行逐句预测 0 差异；words234 两轮 2250 行 0 差异。
2. **学习效应**：万象倒序语料复跑，120/120 句预测与正序逐字一致——lua 组件 userdb（context_reorder/sequence 等 6 个）虽在运行中创建，但经敏感性实测对候选零影响；薄荷 melt_eng.userdb 仅作用英文混输，纯汉字语料不受影响。轮内自积累属方案自身行为，不影响他人成绩，予以保留并记录。
3. **零外源污染**：所有 vendor 目录与本机 `%APPDATA%\Rime` 无任何读写交集；每轮启动前 `remove_all_userdbs` 强制清零。

## 复现命令

```bash
# 整句（约 40-100 s，首次含部署）
python scripts/benchmark_sentences.py --vendors mingyuepinyin rime_ice rime_frost wanxiang oh_my_rime \
  --corpus D:/work/github/IME/windows-ime-bench/corpus/zhihu120.txt --out-dir artifacts_wb1

# 词级
RIME_BENCH_MIN_HANZI=2 python scripts/benchmark_sentences.py --vendors ... --corpus .../words234.txt --out-dir artifacts_wb_words1
```

结论要点：无模型、无用户词库口径下，白霜 > 雾凇 > 薄荷 ≈ 万象 > 明月（基准）；白霜/雾凇词级满分。注意 n=120 时 95%CI≈±9 点，白霜对雾凇 3.3 点的领先在本样本量下属趋势性结论。
