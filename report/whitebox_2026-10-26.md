# Rime 方案白盒横评（2026-10-26）

## 口径

- 引擎：librime 进程内白盒（`lib/rime.dll`），无 GUI、无按键模拟、不开 WeaselServer；
- 输入：连续全拼（无分隔、无声调），句末空格取**首选**；与主仓黑盒口径一致（含归一化：他/她/它→他、的/地/得→的）；
- **读音来源：gold sidecar**（语料同目录 `<stem>.pin.tsv`）——pypinyin 现算结果经
  vendor 词库（雾凇/白霜/薄荷）交叉审计并修正后冻结，评测优先查表；
- 零用户词库：每轮启动前清 `*.userdb`，并以 `{schema}.custom.yaml` 补丁禁用 `translator/enable_user_dict`；
- 隔离：每方案独立 `vendor/<dir>` 作 user_data_dir，与 `%APPDATA%\Rime`（小狼毫桌面配置）完全无关；
- 语料：主仓 `corpus/zhihu120.txt`（整句，n=120，≥5 字）、`corpus/words234.txt`（词级，n=450，≥2 字，`RIME_BENCH_MIN_HANZI=2`）；
- 明月简体 `luna_pinyin_simp` 为基准；魔然（自然码双拼+形码）因输入维度不同，经确认不参与。

## 多音字与读音纪律（根本解法）

逐词补丁（`load_phrases_dict`）只护住已人工核对的语料，换测试集即失效。根治方案
（本轮已落地）：

1. **gold sidecar**：`rime_schema_compare.gold_pinyin` 把语料读音冻结为
   `corpus/<stem>.pin.tsv`，评测优先查表（`text_pipeline.activate_gold_pinyin_for_corpus`），
   无 sidecar 才回退 pypinyin+词补丁；
2. **交叉审计**：`python -m rime_schema_compare.gold_pinyin audit <语料> <sidecar>`
   用本地三家词库（雾凇/白霜/薄荷 dict.yaml，独立注音源）做最长匹配投票——
   词库一致且与 pypinyin 不符 → ERROR 候选；词库互歧或 OOV 含多音字 → REVIEW；
3. **实效**：本轮审计立刻抓出 pypinyin 把「尼泊尔」转成 ní**pō**ěr（湖泊音）的
   错误（3 句，标准音 ní**bó**ěr，三家词库一致作证）——此前两轮人工核对（含
   2026-10-25 全量 570 条）均漏检；修正后 sidecar 审计 0 未决。词级 words234
   读音零修正，sidecar 启用前后 2250 行逐句 0 diff（查表机制的接线验证）。
